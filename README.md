# 태블릿 점검기

이 태블릿 전용 점검 앱입니다. 한 번 설치하면 홈 화면 아이콘으로 열리고 인터넷 없이 동작하며, 검사 결과는 기기 밖으로 나가지 않습니다.

## 검사 항목
- 자동: 배터리, 저장공간, 메모리, 네트워크, 처리 속도, 화면 프레임
- 직접 확인: 터치(불량 구역/멀티터치), 화면 색상(얼룩·죽은 화소), 스피커, 카메라, 마이크, 움직임 센서, 진동

## 설치 (한 번만)
1. 이 폴더 전체를 HTTPS 주소에 올립니다 (예: GitHub Pages). 카메라·마이크·센서·설치 기능은 HTTPS에서만 동작합니다.
2. 태블릿에서 그 주소를 엽니다.
   - Android(Chrome): 메뉴(⋮) → **앱 설치** (또는 홈 화면에 추가)
   - iPad(Safari): 공유 버튼 → **홈 화면에 추가**
3. 이후에는 홈 화면의 "점검기" 아이콘으로 실행합니다. 오프라인에서도 열립니다.

## 수정 후 갱신
파일을 고치면 `sw.js`의 `CACHE` 버전(`tablet-check-v2`)을 올려야 태블릿에 반영됩니다.

## 한계
브라우저가 허용하는 범위만 점검합니다. 배터리 건강도(사이클/용량), 실제 전체 저장공간, Wi-Fi 신호 세기는 읽을 수 없고, iPad는 배터리·메모리·진동 정보를 제공하지 않습니다. 처리 속도 기준값은 추정치입니다.
