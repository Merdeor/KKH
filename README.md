# 태블릿 점검기

태블릿 브라우저(Chrome/Safari)에서 여는 단일 페이지 점검 도구입니다. 설치가 필요 없고, 검사 결과는 기기 밖으로 전송되지 않습니다.

## 검사 항목
- 자동: 배터리, 저장공간, 메모리, 네트워크, 처리 속도, 화면 프레임
- 직접 확인: 터치 반응(불량 구역/멀티터치), 화면 색상(얼룩·죽은 화소), 스피커, 카메라, 마이크, 움직임 센서, 진동

## 사용법
1. `index.html`과 `diag.js`를 같은 폴더에 두고 HTTPS 주소(예: GitHub Pages)로 호스팅한 뒤 태블릿에서 엽니다.
   카메라·마이크·센서는 HTTPS 또는 localhost에서만 동작합니다.
2. 같은 Wi-Fi의 PC에서 `python3 -m http.server 8000` 실행 후 태블릿에서 `http://<PC주소>:8000` 으로 열면 자동 검사와 터치/화면/소리 검사는 가능합니다.

## 한계
브라우저가 허용하는 범위만 점검합니다. 배터리 건강도(사이클/용량), 실제 전체 저장공간, Wi-Fi 신호 세기 등은 브라우저에서 읽을 수 없고, iPad는 배터리·메모리·진동 정보를 제공하지 않습니다. 처리 속도 기준값은 추정치입니다.
