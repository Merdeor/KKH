# 폰 악성코드 점검기 (Android + Windows)

PC에 USB로 연결한 Android 폰의 설치 앱을 **읽기 전용**으로 조회해 의심 신호를 찾습니다. 폰에는 아무것도 설치·변경하지 않고, 데이터는 PC 밖으로 나가지 않습니다.

## 준비 (한 번만)
1. PC에 Python 3 설치 (python.org, 설치 시 "Add to PATH" 체크)
2. Android platform-tools(ADB) 다운로드 후 압축을 풀어 `폰검사\platform-tools\` 에 넣기
3. 폰: 설정 → 휴대전화 정보 → 빌드번호 7번 탭 → 개발자 옵션 → **USB 디버깅** 켜기

## 바탕화면에 설치
```
python install_desktop.py
```
바탕화면에 `폰검사` 폴더와 `폰검사 실행.bat`이 생깁니다.

## 사용
폰을 USB로 연결 → 폰의 "USB 디버깅 허용" 승인 → `폰검사 실행.bat` 더블클릭. 결과 리포트(HTML)가 `내 폴더\폰검사_리포트\`에 저장되고 브라우저로 열립니다.

## 점검 신호 (점수 합산: 3점 이상 주의, 6점 이상 위험)
| 신호 | 점수 |
|---|---|
| 차단 목록(`blocklist.txt`)에 있는 앱 | 10 |
| 접근성 서비스 활성화 | 3 |
| 기기 관리자 권한 | 3 |
| 공식 스토어 외 경로 설치 | 2 |
| 문자 읽기/수신/발신 허용 | 2 |
| 알림 접근, 다른 앱 위 표시, 앱 설치 권한, 백그라운드 위치, 통화기록 | 각 1 |

## 한계
- **의심 신호 탐지이며 악성코드 확정이 아닙니다.** 정상 앱(메신저, 원격제어 등)도 점수가 높을 수 있습니다.
- 시그니처 기반 백신이 아닙니다. 알려진 악성 앱 DB는 포함하지 않으며, 직접 `blocklist.txt`에 패키지명을 추가해 쓰세요.
- iPhone은 지원하지 않습니다.
- 파일 내용 스캔은 하지 않고, 설치 앱의 권한·설치 경로·기기 설정만 봅니다.
